# Security Policy

## Reporting a vulnerability

If you find a security issue in Vallhund Engine or in Vallhund Cloud, please
report it privately:

- Email: **security@vallhund.org**
- Or use GitHub private vulnerability reporting on this repository if enabled.

Please include reproduction steps and an assessment of impact if you can.
We aim to acknowledge reports within 72 hours.

Please do not open public issues for suspected vulnerabilities.

## Scope notes

- This repository contains pure judgment logic and credential-free checks. It
  does not handle credentials or customer data; issues involving those belong
  to Vallhund Cloud and are still welcome at the address above.
- Detection-evasion reports (inputs the engine should catch but does not) are
  welcome as private reports too. Evasions are treated as bugs.
